OLD CARPENTER'S NOTEPAD — GITHUB PAGES PACKAGE

Upload ALL of these web files in this folder to a GitHub repository:
index.html
measurements.js
manifest.webmanifest
service-worker.js
icon-192.png
icon-512.png

Then enable GitHub Pages for the repository.

On iPhone:
1. Open the GitHub Pages address in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.

The app then opens from its own Home Screen icon.

IMPORTANT: This prototype currently stores notes in Safari/local app storage on that device
and syncs to your private cloud account after sign-in.
Do not use it as the only copy of irreplaceable information yet.

Version 1.5 adds Measurements & Sketches (shop drawings with automatic dimensions).
A recovery copy of the previous release is in Backup_before_measurements_v1.4_2026-10-30/.
