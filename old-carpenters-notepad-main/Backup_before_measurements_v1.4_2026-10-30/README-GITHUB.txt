OLD CARPENTER'S NOTEPAD — GITHUB PAGES PACKAGE

Upload ALL FIVE web files in this folder to a GitHub repository:
index.html
manifest.webmanifest
service-worker.js
icon-192.png
icon-512.png

Then enable GitHub Pages for the repository.

On iPhone:
1. Open the GitHub Pages address in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.

The app then opens from its own Home Screen icon.

IMPORTANT: This prototype currently stores notes in Safari/local app storage on that device.
Do not use it as the only copy of irreplaceable information yet.
