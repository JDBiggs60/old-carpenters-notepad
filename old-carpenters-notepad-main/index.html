Quick Help

1. Create a project — From Measurements & Sketches, tap New Project and name it (Kitchen Cabinet, Bluebird House, etc.).

2. Draw a rectangle from sizes — Tap Draw From Measurements, choose Rectangle, enter Width 36 and Height 24, then Create. Dimension arrows appear automatically.

3. Change a size — Select the rectangle, change Width to 42, tap Update Size. The shape and the 42" dimension both change.

4. Manual dimension arrows — Choose Dimension, then tap the first point and the second point. The measured length appears automatically.

5. Photos — Photos tab → Add Photo. Tap the photo to place reference arrows and type the size.

6. Dictation — On List tab, dictate into the text box with your keyboard mic, then Interpret and confirm.

7. Save / Print — Tap Save often. Print makes a fit-to-page layout (not labeled as actual size).

Measurements & Sketches Help

Think of this like a simple paint program that understands inches.

Automatic dimensions: shapes created from measurements keep dimension arrows attached. If you change 36" to 42", the rectangle grows and the label becomes 42".

Fractions: type 36 1/2, 5 1/4, 3/4, or 12.75. Switch inches/mm anytime — the real size stays the same; only the label changes.

Freehand pencil: useful for quick sketches. Freehand lines are not treated as precise measured geometry.

Photos / Apple Measure screenshots: import as pictures, then type reference arrows. The app does not read scale from the camera.
